# Optional celebration images

Add your own images here:
- `images/overtake/you-overtook.png`
- `images/congratulations/monthly-champion.png`

Keep graphics lightweight (< 250 KB where possible); PNG or WebP files work well. The application falls back to text when an image is not present. The default profile avatar is `images/default-avatar.svg`. Do not upload confidential company imagery without permission.
